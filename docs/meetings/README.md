# Meeting Notes Guidelines

## Filename Conventions and Storage

### Storage Directory
All meeting notes must be stored in the codebase repository under:
`docs/meetings/`

### File Naming Format
Files should be named using the date in `YYYY-MM-DD` format followed by a short context title in kebab-case:

`YYYY-MM-DD-short-title.md`

#### Examples:
* `docs/meetings/2026-03-15-sprint-review.md`
* `docs/meetings/2026-04-02-sprint-defense.md`
