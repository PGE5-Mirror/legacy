# Daily Standup Template

Use this file as the standup template. Copy or duplicate it and name the copy using the format `YYYY-MM-DD-daily-standup.md` (for example: `2026-09-14-daily-standup.md`).

## Convention
- The first bullet under each person is **Yesterday / Done** (what they completed previously).
- The second bullet under each person is **Today / In progress** (what they're working on next).
- Use a `Blocker:` prefix for items that are blocking progress.
